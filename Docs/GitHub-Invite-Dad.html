Inviting Dad to GitHub

The repositories sit under the SmartCubeMobile organisation, so invite him to the organisation and he gets both at once.

  1. Go to github.com/orgs/SmartCubeMobile/people and click Invite member.
  2. Type his GitHub username, or the email address he used for GitHub, then Invite.
  3. On the next screen choose his role. Owner gives him the same rights as you. Member lets him work on the code only.
  4. If you chose Member, also give him access to the two repos so he can push. Open github.com/orgs/SmartCubeMobile/teams, create a team (any name, such as "Developers"), add him, then on the team's Repositories tab add smartcube-app and smartcube-server with Write access.
  5. He gets an email from GitHub and accepts the invitation. He needs his own GitHub account first if he doesn't have one.
Simplest choice: pick Owner in step 3 and skip step 4. For two people working together that's reasonable.

He can then clone both repos with the commands in the shared-development memo. The first git push from his PC asks him to sign in to GitHub in a browser.
